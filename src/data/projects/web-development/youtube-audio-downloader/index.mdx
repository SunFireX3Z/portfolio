## Latar Belakang

Proyek ini mengeksplorasi integrasi antarmuka web dengan backend Python untuk pemrosesan audio.

## Tujuan Proyek

- Menerima URL video dari pengguna.
- Menampilkan informasi video.
- Menyediakan proses pengunduhan audio.

## Implementasi

Jelaskan bagaimana antarmuka React berkomunikasi dengan backend Python dan bagaimana informasi video diproses.
